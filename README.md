# PIMPON

Maquette pédagogique d’intervention de pompiers avec feu simulé et deux ESP32.

L’application iPhone **Fire Control** (SwiftUI, iOS 17+) comprend un mode simulation autonome et prépare le raccordement Wi-Fi/WebSocket du camion et de la maison. Le déplacement du camion reste commandé exclusivement par sa télécommande physique.
